# Aura Textures

20 white-on-transparent particle and UI textures, drawn procedurally for the Sol's RNG-style Modifier auras in **Clone a Friend** (`ReplicatedStorage.AuraFX`). Uploaded to the creator's account and registered in `ReplicatedStorage.VFXTextures`. Roblox tints them with `Color` / `ImageColor3`.

Source images and the generator are in this folder (`make_textures.py`, run with Python + Pillow + NumPy). The Wing was redrawn by hand afterwards, so the generator's wing code is the older version.
