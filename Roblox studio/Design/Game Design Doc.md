# Game Design Doc: Coin Collector

> [!info] Example project
> This whole vault is filled with a made-up simulator so the tables have something to show. Replace it with your own game.

**Pitch:** Run around a map collecting coins, buy speed and magnet upgrades, rebirth for a permanent multiplier.
**Audience:** 8–14, mobile first.
**Session length:** 10–20 min.

## Core loop
Collect coins → buy upgrades → collect faster → unlock new zone → rebirth.

- [[Shop]]

## Monetization
- Game pass: 2x coins
- Developer product: coin packs

## Milestones
- **M1 – Playable:** coin collection, saving, HUD
- **M2 – Progression:** shop, upgrades, second zone
- **M3 – Retention:** rebirth, daily rewards
