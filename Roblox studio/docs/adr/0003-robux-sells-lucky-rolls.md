# Robux sells Lucky Rolls despite Rarity giving an edge

Because higher Rarity gives more options in PvP (ADR 0001), selling Rolls is a soft form of pay-to-win. We accept that, as Blue Lock: Rivals does: Robux buys Lucky Rolls only, every Roll counts toward the same Pity, and Daily Quests give a free path to Lucky Rolls. This only stays fair while ADR 0001 holds: every Common Class must remain able to win.
